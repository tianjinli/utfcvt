# utfcvt - 多字节到 Unicode 转换工具

**中文 | [English](README.md)**

### 项目概述

**utfcvt** 是一个 Windows 桌面应用程序和命令行工具，用于在各种字符编码之间转换文本文件，特别是将 MBCS（多字节字符集）转换为 Unicode/UTF-8。提供直观的 GUI，完全支持多语言（英文和中文）。

### 核心功能

- **批量处理**：递归扫描并转换整个目录树中的文件
- **图形界面 & 命令行**：同时提供 GUI 和 CLI 两种使用方式
- **多语言界面**：支持英文和中文（简体）两种界面语言
- **异步处理**：使用 C++ 协程确保大量文件转换时 UI 保持响应
- **灵活筛选**：支持排除特定文件夹，按文件扩展名筛选

### 系统要求

- **编译器**：Visual Studio 2022 及以上版本（需要 C++23 协程支持）
- **平台**：Windows（使用 Win32 API）
- **字符集**：Unicode/UTF-8 项目配置

### 使用方法

#### GUI 模式

1. 启动 `utfcvt.exe`
2. 选择源和目标文件夹
3. 配置文件扩展名和要排除的文件夹
4. 选择源和目标编码
5. 点击"开始转换"按钮开始处理

#### 命令行模式

```bash
utfcvt --help
```

支持的选项包括源/目标编码、文件扩展名、排除文件夹等。

### 编译构建

1. 使用 Visual Studio 打开 `utfcvt.sln`
2. 选择所需的配置（Debug/Release）
3. 编译解决方案

### 测试

`Data/` 目录下提供了测试文件：
- `ANSI.txt` - ANSI/GBK 编码文件
- `UTF8.txt` - UTF-8 编码文件
- `UTF8BOM.txt` - 带 BOM 的 UTF-8 文件
- `UTF16LE.txt` - UTF-16 LE 编码文件
